## PART 2: DIAGNOSTIC ANALYSIS (the three F-calibration 
## hypotheses)

The reviewer proposed three specific mechanisms for F's 
underconfidence. Test all three using the EXISTING SBC data 
(no retraining needed). Each is a conditional analysis — 
grouping the existing results by a variable and checking whether 
coverage varies.

### 2.1 Hypothesis 1: Per-parameter validation loss comparison

Question: does F's validation loss plateau earlier and at a 
relatively higher value than other parameters, suggesting the 
encoder isn't extracting F's signal efficiently?

Method: if the training log records per-parameter losses 
(separately for f_d, F, host_median, host_sigma), compare their 
trajectories. If per-parameter losses aren't recorded, compute 
them post-hoc: run the trained model on the validation set and 
compute the per-parameter posterior width (a proxy for how well 
each parameter is constrained).

Alternative method: compute the per-parameter posterior width 
(median across validation catalogs) relative to the prior width. 
If F's contraction is systematically less than other parameters' 
(relative to what's achievable), that points at a 
representational issue.

Report: per-parameter contraction ratios, and whether F is 
disproportionately undercontracted.

### 2.2 Hypothesis 2: Coverage conditioned on true F position in 
## prior

Question: is F's coverage worse for catalogs where the true F is 
near the prior boundaries (0.02 or 1.0) vs. the middle (~0.3)?

Method: using the existing SBC results (1000 trials), group trials 
by the true F value:
  - F in bottom quartile of prior: F < ~0.1
  - F in middle: 0.1 < F < 0.5
  - F in top: F > 0.5

For each group, compute the empirical coverage at 68% and 95%. 
If coverage is significantly worse in the tails vs. the middle, 
the logit transform is compressing gradients where resolution is 
needed.

Report: coverage by F-position group, with trial counts.

### 2.3 Hypothesis 3: Coverage conditioned on localized fraction

Question: is F's coverage worse for catalogs with mostly 
unlocalized bursts vs. mostly localized?

Method: using the existing SBC results, group trials by the 
localized fraction of the catalog:
  - Mostly unlocalized: ℓ < 0.15
  - Mixed: 0.15 < ℓ < 0.35
  - Mostly localized: ℓ > 0.35

For each group, compute empirical coverage at 68% and 95% for 
ALL parameters (not just F — check whether f_d, host_median, 
host_sigma coverage also varies by composition).

If F's coverage is fine for localized-heavy catalogs but poor for 
unlocalized-heavy ones, that means F genuinely requires localized 
bursts — which is a PHYSICS finding (per-parameter exchange 
rates differ), not a bug.

If F's coverage is poor even for localized-heavy catalogs, that 
means the encoder has a representational issue — it's not 
extracting the scatter information even when it's available.

Report: per-parameter coverage by localized-fraction group, with 
trial counts. THIS IS THE MOST IMPORTANT DIAGNOSTIC — it 
determines whether F's underconfidence is (a) physics (F needs 
localized bursts) or (b) architecture (the encoder isn't looking 
at the right features).
